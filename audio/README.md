# Carpeta de audio — El Pantano

Colocá acá los archivos de música y efectos con estos nombres exactos (minúsculas):

## Música (loop, por escena)
- `menu.mp3` — menú, instrucciones y la escena inicial (el despertar)
- `bosque.mp3` — escenas del bosque
- `pantano.mp3` — escenas del pantano
- `canto.mp3` — escenas del canto
- `final.mp3` — la encrucijada final

## Efectos de sonido
- `fragment.mp3` — al recuperar un fragmento de memoria
- `choice.mp3` — al elegir una opción

Si falta algún archivo, el juego sigue funcionando en silencio para esa pista puntual (no rompe nada).

Este README no afecta al juego — es solo una guía. Podés borrarlo cuando esté todo cargado.
